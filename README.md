# joineffall2026

A private network search for one EF cohort. Members upload their LinkedIn
connections export; anyone in the cohort can search the combined result and see
who can make the introduction.

The code is public so members can read exactly what happens to their upload.
The cohort roster, the photos and the database are not in this repository —
they live on the server's volume. See [the plan](docs/plans/2026-09-22-batch-network-bank.md).
